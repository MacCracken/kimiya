# Contributing to Kimiya

## Workflow

1. Fork and clone
2. Create a feature branch
3. Make changes following the development process in CLAUDE.md
4. Run the cleanliness check (below) — it must be clean, and `cyrius test` warning-free
5. Add tests and benchmarks for new code
6. Submit PR

## Cleanliness check

```sh
cyrius deps
cyrius fmt --check
cyrius lint
cyrius vet
cyrius build src/main.cyr build/kimiya
cyrius test                 # must be warning-free, not just passing
cyrius test --bounds
cyrius bench
cyrius distlib --all && cyrius distlib --check
cyrius deps --locked
cyrius audit
python3 -I -B scripts/surface_parity.py .
python3 -I -B scripts/rust_test_ledger.py . --check
```

## Code Style

- `cyrius fmt` enforced; `cyrius lint` and `cyrius vet` clean
- Public enums have explicit, append-only numeric values; property functions `match` with an `_ =>` arm
- `#must_use` on pure functions, plus `#pure` where it applies
- No aborts in library code: no `+?`, `-?`, `*?`, `assert_fatal` or `result_unwrap` in `src/`; errors return a
  value-form `Result` or an `err_out` code, and every guard rejects NaN and ±∞
- f64 hygiene as in CLAUDE.md (bind call results to `: f64` locals, no hex in a `const`, `-x` not `(0 - x)`)
- Tables and constants are generated by `scripts/oracle/`, never edited by hand
- Every public global carries the `KM_` prefix; private helpers use `_km_`
- All chemistry implementations must include correctness tests with known values from a cited primary source

## Testing

- `cyrius test` — the reference tests (`tests/*.tcyr`) and the golden parity corpus (`tests/parity.tcyr`)
- `cyrius test --bounds`, `--win` and `--aarch64` — the same suite with bounds checks, on x86_64 PE and on aarch64
- `cyrius bench` — `tests/*.bcyr`; record numbers against Rust in `docs/benchmarks-rust-v-cyrius.md`
- The golden corpus is regenerated from the Rust oracle in `rust-old/` (read-only):
  `cargo run --release --locked --manifest-path scripts/oracle/Cargo.toml -- --check`, and checked independently by
  `python3 -I scripts/oracle/validate.py .`
